# OMiPLU_QGIS
## Transposition de la ToolBox OMiPLU sous QGis

L'objectif de ce projet est de transposer la ToolBox [OMiPLU](https://omiplu.mikkrogeo.com) ArcGISpro en extension QGis

[OMiPLU](https://omiplu.mikkrogeo.com) est une ToolBox ArcGISpro permettant de migrer n'importe quelle donnée PLU vers le [standard CNIG PLU](https://github.com/cnigfr/schema-plan-local-urbanisme)

### Le projet est transféré vers le projet [PLU SIG OPENSOURCE](https://gitlab.com/plu-sig-opensource/omiplu-qgis)
